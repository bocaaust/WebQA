      What do the results mean?
      Passed means that particular check found no problem. Needs attention means a person should review the website and the test expectation. Could not run usually needs help with setup. Not checked means there is no result for that check. A passing run does not guarantee that a website is fully accessible.
      Open the full report and share the check name and technical details with your website team. Do not ask AI to remove a failing check just to get a passing result.
      

      How do I use AI?
      Choose a website and a model, describe what a visitor should be able to do, and select Prepare tests. Read the plain-language proposal, select Use these tests, then Run AI tests. You do not need to read or edit Python code.
      If no model is listed, start Ollama and select Refresh models. If the list is still empty, ask your setup helper to install and verify a model. Ordinary website checks remain available.
      

      What if a check cannot start?
      If the report says the browser is missing, ask your setup helper to rerun Setup-WebQA. If no checks matched, select All configured checks. For a website address error, open the website normally and copy its final main address, including www if present.
      Keep the launch window open. If you accidentally close it, open Start-WebQA again. Your saved websites, tests, and latest completed results remain available.
      

      Runs stay on this computer. The assistant uses your local Ollama service. Website checks make ordinary page requests, run one at a time, and block form submissions. Keep this app’s launch window open while using it.
