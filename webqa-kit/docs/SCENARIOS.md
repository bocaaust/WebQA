# Scenario justification and prioritization

P0 protects customer or recruiting entry paths. P1 covers important supporting behavior and accessibility. P2 covers lower-frequency informational pages. These are test scheduling priorities, not defect severity: a P1 accessibility test can expose a release-blocking defect.
